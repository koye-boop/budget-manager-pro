## Budget Manager Pro

Application de gestion de budget développée en JavaScript ES6+.

---

## Fonctionnalités

- Ajout de revenus et dépenses
- Calcul automatique du solde
- Catégorisation des transactions
- Affichage dynamique en temps réel
- Graphique interactif (Chart.js)
- Sauvegarde locale (localStorage)
- Affichage date et heure des transactions

---

##  Technologies utilisées

- HTML5
- CSS3
- JavaScript ES6+
- Modules JS (import/export)
- Chart.js
- LocalStorage API

---

## Architecture

- `main.js` → logique utilisateur
- `financeService.js` → logique métier
- `ui.js` → interface utilisateur
- `storage.js` → persistance des données
